# Pokèthereum 

An example in quantitative finance engineering to show how game-theory incentives driven from Pokèmon can
be modelled in EVM blockchain based network activity. 

The idea for Pokèthereum was founded after an editorial publication in a local connections magazine from the New Finance Initiative's CEO & director - https://asknights.org/imaginary-behaviour-a-brief-letter-on-the-un-conventional-aesthetics-of-psychological-enjoyment-pokemon-as-an-nft-business/
